# 《星际猎人》游戏语境：术语与创作核对

适用：原片或策划目标涉及《星际猎人》。该作品的当前开发者产品页使用《星际猎人-无尽的拉格朗日全面焕新》名称；《无尽的拉格朗日》是同一作品此前使用的名称，不按两款游戏处理。只在本次用户明确指定或原片证据确认时调用本参考；技能仍可拆解其他游戏，不把未指定的目标自动设成《星际猎人》。核验日：2026-10-10。

本文件是**识别和核对词义的索引**，不是台词库、当前版本的完整规则书或剧情事实来源。先从本次视频/图文定位实际出现的词，再查该玩法所在星系、协议、客户端版本与官方公告。过往前瞻只证明当时提出过某种设计，不能证明现版本的数值、资格、效果或所有星系都适用。不要因画面有飞船就推定具体舰名、势力或战术。

## 作品特色与可迁移观看任务

开发者介绍以舰队编组、星系探索、赏金任务、遗迹寻宝、基地成长、势力往来和多人协作为主要内容，并强调可近距离呈现的三维舰船战斗。这给创作提供了不同的观看任务：看懂一次选择为何冒险、看清舰队配置如何应对目标、跟随一趟探索揭示信息、理解多人分工，或欣赏舰船设计细节。拆解时说明**原片实际上使用了哪一种**，不能全部强加。策划时让目标观众、素材和游戏内可完成的动作彼此对应。[开发者产品介绍](https://apps.apple.com/cn/app/id1449701587)、[全球官网特色](https://www.infinitelagrange.com/)。

## 给拆解与下一条策划的用法

1. 原片术语按实际时间点/页码记录：**原声或字幕原词 → 本次画面支持什么 → 官方名称是否核准 → 所属版本/协议 → 不确定处**。口误、昵称和玩家黑话不要静默改成官方名称。
2. 改编另一个游戏的视频时，只迁移「探索未知／舰队选择／合作分工／风险与收益／工业与后勤」等叙事和观看任务；新脚本必须用《星际猎人》能核实的角色、空间、动作与素材重写。原片属于 EVE 时，不把其装配槽位、探针扫描、军团主权中心、ISK、虫洞等专有机制写成《星际猎人》事实。
3. 三条策划可分成不同方向，例如一次赏金任务的取舍、一次蓝图与舰队配置的验证、一段势力/小队协作故事。它们只是候选方向；先看用户提供的原片结构和目标受众，再决定是否适用。完整对白必须原创、可演，并与画面动作和真实可录素材一致。
4. 每遇到具体数值、概率、舰船性能、赛季规则或活动资格，查对应日期的官方公告与游戏内当前界面；没有核实就写「待核」，不可把旧网页当现行承诺。想做世界观演绎可以虚构事件，但要与已知设定相容，并标明非实录。

## 同题材参照仅用于提问，不移植设定

[EVE 官方介绍](https://www.eveonline.com/)把探索、工业、贸易、战斗和玩家组织视为不同的活动路径；[EVE 装配窗口](https://support.eveonline.com/hc/zh-cn/articles/213287845-%E8%A3%85%E9%85%8D%E7%AA%97%E5%8F%A3)、[扫描说明](https://support.eveonline.com/hc/en-us/articles/203209902-Scanning)、[组织项目](https://www.eveonline.com/news/view/stronger-organizations)展示了如何把专业操作讲成「准备、风险、选择、结果」的观看过程。可借鉴的是**解释复杂决策的方式**；EVE 的职业、经济、舰船装配、扫描和主权规则均不等于《星际猎人》的玩法。其他太空策略作品同理，只有经目标游戏官方来源或本次游戏内证据确认的机制才能进入脚本。
