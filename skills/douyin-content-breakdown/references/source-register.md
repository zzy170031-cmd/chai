# 来源登记与核验入口

本文件包含公开官方/研究来源及登记规则。用户提供的文档链接、原始教材、媒体和项目专属信息不随 skill 发布；在用户工作目录的分析报告中维护其阅读记录。

## 知识准入

本库平台事实只收抖音官方依据。个人在douyin.com发文也不自动属于官方；搜索摘要、聚合页和AI搜索概览仅作导航。其他平台流量算法、运营阈值与分发经验不入库。通用心理/传播研究仅能支持内容设计假设，必须写明研究情境，不能变成抖音效果或权重。

知识项最小登记：`id｜主张｜性质（官方说明/通用研究/案例观察/设计假设）｜source_id与原始出处位置｜支持范围｜不支持的推论｜适用形式｜反例｜核验日期｜更新触发｜状态`。作品结论继续使用主技能的观察/测量/来源/假设分类；来源类型不能代替因果强度。

稳定原理在出现反证、适用人群变化时复核；平台规则在用于当次行动前复核；热点在提出当前推荐时复核。未核验条目标为历史/候选，不阻断不依赖它的内容分析。原源撤回或互相冲突时保留差异，暂停确定性引用。多个镜像或转述归入同一来源组。
