# 读取路径

## 链接

1. 用浏览器解析分享链接，检查真实落地内容。保留原 URL 与落地 URL，避免把推荐栏作品当目标。
2. 先核对媒体类型与实际播放／翻页能力，再读取正文、画面、声音和可见计数。先读公开内容；受登录等限制的内容按环境授权规则处理。
3. 若工具调用超时，检查已有标签和页面状态，不能仅凭工具报错认定网页不可读。对同一阻塞不要无限重试。
4. 读取不足时具体说明缺的是媒体、声音、后半段还是评论。评论不是内容拆解必需输入；没有后台数据不阻塞结构分析。
5. 请用户补本地文件前，保留已有身份信息。文件补充后核对版本。

链接工具的可访问性取决于运行环境。Skill 是指导工作流，不自带网站访问授权、语音模型、视频理解接口或平台数据权限。发现真实工具再使用，不虚构调用。

## 本地视频

在有 Python 3、ffprobe、ffmpeg 的环境运行：

```text
python scripts/inspect_video.py "输入视频.mp4" --out "新建证据目录"
```

输出 `metadata.json`、`frames.json` 和带时间编号的 PNG。默认最多 12 帧，仅用于初步定位，不能替代完整阅读。需要观察具体时刻：

```text
python scripts/inspect_video.py "输入视频.mp4" --out "另一新目录" --times 0,1.5,6.2,12
```

需要音轨时增加 `--audio`，只导出最多 15 分钟、单声道 16 kHz WAV；更长视频先分段规划。该 WAV 是语音分析辅助文件，音乐与声场判断应回到原始音轨。脚本不安装模型、不联网、不转写，不更改原视频；输出目录必须不存在，以避免覆盖证据。

查看输出图像，并按切点、闪字和语义变化补读。查验口播、音乐和音效需要运行环境中实际可用的能力；只有抽帧或音轨存在性不能声称听过音频。未配置转写时不隐藏该缺口，不要求用户为试用此 skill 先安装整个前端。

可保留原始文件指纹、尺寸、时长、实际读取区间、抽样计划和导出时间。大型文件的哈希计算按当前环境健康约束执行；未计算就标明未计算。
