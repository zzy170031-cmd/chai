# 读取路径

## 链接

1. 用浏览器解析分享链接，检查真实落地内容。保留原 URL 与落地 URL，避免把推荐栏作品当目标。
2. 先核对媒体类型与实际播放／翻页能力，再读取正文、画面、声音和可见计数。先读公开内容；受登录等限制的内容按环境授权规则处理。
3. 若工具调用超时，检查已有标签和页面状态，不能仅凭工具报错认定网页不可读。对同一阻塞不要无限重试。
4. 读取不足时具体说明缺的是媒体、声音、后半段还是评论。评论不是内容拆解必需输入；没有后台数据不阻塞结构分析。
5. 请用户补本地文件前，保留已有身份信息。文件补充后核对版本。

链接工具的可访问性取决于运行环境。Skill 是指导工作流，不自带网站访问授权、语音模型、视频理解接口或平台数据权限。发现真实工具再使用，不虚构调用。

## 本地视频

在有 Python 3、ffprobe、ffmpeg 的环境运行：

```text
python scripts/inspect_video.py "输入视频.mp4" --out "新建证据目录"
```

输出 `metadata.json`、`frames.json` 和带时间编号的 PNG。默认最多 12 帧，仅用于初步定位，不能替代完整阅读。需要观察具体时刻：

```text
python scripts/inspect_video.py "输入视频.mp4" --out "另一新目录" --times 0,1.5,6.2,12
```

需要音轨时增加 `--audio`，只导出最多 15 分钟、单声道 16 kHz WAV；更长视频先分段规划。该 WAV 是语音分析辅助文件，音乐与声场判断应回到原始音轨。脚本不安装模型、不联网、不转写，不更改原视频；输出目录必须不存在，以避免覆盖证据。

查看输出图像，并按切点、闪字和语义变化补读。查验口播、音乐和音效需要运行环境中实际可用的能力；只有抽帧或音轨存在性不能声称听过音频。未配置转写时不隐藏该缺口，不要求用户为试用此 skill 先安装整个前端。

可保留原始文件指纹、尺寸、时长、实际读取区间、抽样计划和导出时间。大型文件的哈希计算按当前环境健康约束执行；未计算就标明未计算。

## 可选取证能力

以下仅为候选，不是已接入或必装依赖。按环境权限、资源和素材范围另行试验，不默认上传原片；工具不可用不阻塞已有证据的有限分析。

- [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR)：可用于人声转写，时间定位需核对所用模式及对齐能力；流式不自动返回时间戳。核验游戏专名与漂移，静音/无人声配乐不能臆造台词；有歌词的转写也不等于音乐作用分析。
- [PySceneDetect](https://www.scenedetect.com/docs/latest/api/detectors.html)：像素变化产生候选点；闪光/UI可误切，长镜头可漏语义变化。分别核验切镜与内容节点，不把候选点视为高潮或完整覆盖。
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper)：可选本地转写草稿和词级时间定位；须实际遍历转写结果并检查完成范围。游戏专名、抢话及听不清处逐句核对，不能用词表强行覆盖不明原声。VAD过滤掉的无语音区间可能仍有音乐、静默或动作意义；没有转写不等于没有内容。更复杂的对齐和说话人分离仅在明确缺口需要时另行评估。
- [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)：辅助识别字幕、界面文字或图文正文，保留对应时间／页码、原图位置与不确定字。OCR不自动提供字幕持续时间；动态花字、遮挡和短闪需要局部复查。一个镜头内字幕或说话人变化仍可构成多个拆解单元。

只按真实观察补读关键前后关系。闪字仍不可读、声音不可理解或资源耗尽时，记录相应缺口并停止该范围的确定断言；不以12帧、ASR文本或切点列表代替完整阅读。候选能力说明核验日2026-09-23；实际运行与准确性未验收。

## 使用候选前的有限检查

工具、依赖、模型和许可按实际选择核验；不因参考文件列出工具就自动安装或声称已接入。E03登记已查的代码许可，不替代模型权重及具体发行件的条件。优先本地处理；外部服务、云端转写或额外持久化需要已有明确授权，否则不能把本地失败自动改成上传。必要的本次抽帧、转写和交付文件不等于长期案例库，不默认跨任务索引或复用私人素材。

区分「媒体可访问范围」「机器实际处理范围」「实际视听核对范围」；候选区间与已回看区间分开，模型收到整个文件不等于完整观察。时间戳注明工具估计、对齐或人工核对的精度，字段存在不证明定位准确。链接获取仍需验证具体作品：浏览器可播放、取得媒体、音画完整和拆解完成是不同状态，不根据下载器支持列表承诺所有抖音链接成功，也不导出整套浏览器凭据或绕过访问限制。

修改读取能力后，用授权素材针对受影响分支验收，而不是每次拆解都跑全套测试：

| 场景 | 实际检查与失败条件 |
|---|---|
| 六分钟对白、打断及专名 | 核对首尾与逐轮证据、漏句和不明处；没有听审能力就不能通过完整对白验收。 |
| 快切、短闪、长镜头内换字幕 | 对照实际素材确认关键内容；只读抽样帧时，不把未采到的事件判为不存在。 |
| 无音轨与有音轨但未听 | 分别披露媒体事实与能力缺口，不补造声音。 |
| 多页图文或部分视频 | 页序／已读区间可定位，缺失页与时段明示，不补造全片。 |
| 禁止云端而本地能力不足 | 无未经授权的外发动作，保留可完成的有限分析。 |

以上是验收设计，未执行记“未测”，受限不折算通过。判断增补是否改善效果时，对同一授权素材比较旧版与新版的实际证据和产物；格式校验不能代替内容准确性。只保留本次测试必要材料，不自动收集用户历史作品成测试库。
