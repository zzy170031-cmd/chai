# 标准提问话术与调用提醒

用于本技能的新作品入口。用户只输入技能名、询问怎么用或缺少必要信息时，告诉用户可以直接发抖音链接，也可以附本地视频／图片；先核对能读取的内容，不要求用户预先下载。链接可读性、声音与字幕覆盖须实际检查，不能承诺仅凭链接一定完整分析。

## 可复制的需求模板

```text
$douyin-content-breakdown 拆解这个作品：[抖音链接或附上的本地素材]
原片拆解范围：[全片／全部图文，或指定时间段／页码]
目标游戏或题材：[填写；不做题材迁移可写“沿用原题材”]
下一条策划：[不需要，或3条短视频／图文方案]
策划篇幅：[沿用原片大致体量完整展开，或完整展开至约X分钟／X页，或提取指定部分改成约X秒／X页]
输出：[Excel或其他明确格式]
有明确对话时逐轮拆解；新策划保留创作指导，并给出完整原创对白／口播及画面动作。
```

只要原片拆解时可省略目标游戏与策划篇幅，写明不需要下一条策划即可。只做图文时按页序给画面与文案，不强加人物对话。目标游戏决定新策划，不把原片自动认成该游戏。

完整展开示例（仅作用户选择示例，不是自动采用的默认范围）：

```text
$douyin-content-breakdown 拆解这个链接：[粘贴链接]
全片拆解，目标游戏：率土之滨。
输出Excel，并给三条抖音短视频策划；三条都沿用原片大致体量完整展开。
原片对话逐轮分析；策划同时保留创作指导、完整原创台词和画面动作。
```

## 提醒与补问规则

- 新作品首次处理时，简短提示上述写法。若用户已给齐信息，用一句话复述已确认的范围与目标即可，不重复塞整段模板，也不要求重发需求。
- 缺项时先说明「可以照此模板发；已提供的内容无需重复」，展示模板或与缺项有关的短版。只追问影响下一步的范围、目标或篇幅，不扩大成账号调查、受众档案或固定问卷。
- 「完整」与「部分」分别用于原片拆解和新策划。具体执行遵循[范围与篇幅确认](creator-context.md#范围与篇幅确认)；用户尚未选择、未替换占位符或未回答时，不能自动默认全片、约六分钟、两分钟短版等。
- 原片时长尚未知时，用户可以明确选择「沿用原片大致体量」。核对后说明实际时长与拟采用体量；读取不到的内容另行报告，不把选择全片误当成已读完整。
- 若用户的回答改变了本次范围，按最新明确回答更新；同一作品已确认的内容不重复问。新作品不静默套用上次的游戏、时长和素材条件。
- 提醒只用于解释如何发起当前需求，不会自动建立用户档案、收藏原片或上传本次素材到仓库。
